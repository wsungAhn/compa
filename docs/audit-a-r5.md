## 이 라운드의 결정적 발견

**#1이 이번 무인 작업의 전제를 깼다.** 지시서 Phase 4는 "구현 → kickstart → 20분 관찰"인데,
운영 서비스가 main 체크아웃을 물고 있어 **워크트리 커밋만으로는 절대 반영되지 않는다.**
반영하려면 main 머지가 필요하고, main 머지는 지시서가 명시적으로 금지했다
("main 브랜치 머지 금지").

추측으로 우회하지 않는다. 검토했다 기각한 우회로:

| 우회로 | 왜 안 하나 |
|---|---|
| plist `WorkingDirectory`를 워크트리로 변경 | **프로덕션 설정 파일 수정 금지** |
| 워크트리에서 워커를 수동 기동 | 같은 Redis 큐를 운영 워커와 경합. "그 외 서비스는 건드리지 마라" 위반 |
| main 머지 | **명시적 금지** |

→ **Phase 1~3까지 수행하고 Phase 4는 사용자 승인 대기로 남긴다.**
