## 1번. Impact.com 제휴 계정 신청

**왜 이거부터인가**: 확인된 것만으로 브랜드 4개(Herbivore, ILIA, Kosas,
Natasha Denona)가 한 계정으로 잡힌다. 코드 수정 없음 — 계정 신청 후 발급되는
추적 링크를 `.env`에 붙여넣기만 하면 끝.

### 순서

1. **가입 페이지 열기**: 브라우저에서 `app.impact.com` 접속 → "Become a Partner"
   또는 "Sign Up" 버튼 클릭 (화면 우측 상단 또는 중앙에 있음).
2. **계정 종류 선택**: "Partner"(광고주가 아니라 광고를 실어주는 쪽) 선택.
   compa는 화장품 가격을 비교해주고 그 링크로 판매를 유도하는 쪽이라 Partner가 맞음.
3. **가입 폼 작성**:
   - 웹사이트 URL: `compa.mwco.io` (또는 지금 배포된 실제 도메인)
   - 사업 설명: "화장품 가격 비교 서비스 — 여러 국가/플랫폼의 할인 이력을
     보여주고 구매 링크를 연결" 정도로 적으면 됨
   - 이메일/연락처: 본인 정보
4. **승인 대기**: Impact.com은 보통 며칠 내로 심사 결과를 이메일로 준다.
   심사에서 "웹사이트가 실제로 운영 중인지"를 볼 수 있으니, **compa가
   실제로 접속 가능한 상태**(지금은 서비스 재기동해둔 상태라 OK)일 때
   신청하는 게 유리하다.
5. **승인되면 개별 브랜드에 추가 신청**: 계정 승인 = 네트워크 가입일 뿐,
   브랜드별로 한 번 더 "이 브랜드 프로그램에 참여하겠다" 신청이 필요할 수
   있다. Impact.com 대시보드 안에서 "Discover" 또는 "Marketplace" 탭에서
   Herbivore, ILIA, Kosas, Natasha Denona를 검색해 각각 참여 신청.
6. **추적 링크/ID 받기**: 브랜드별 승인이 끝나면 각 브랜드 상품 페이지에
   붙일 "Program ID" 또는 추적 파라미터를 대시보드에서 확인할 수 있다.

### 끝나면 나(Claude)한테 시킬 일

Impact.com이 브랜드별로 발급하는 추적 방식(URL 파라미터 추가 방식인지,
전용 딥링크 생성 API인지)은 브랜드마다 다를 수 있다. **승인 통지 이메일이나
대시보드 화면을 캡처해서 보여주면**, `app/core/affiliate.py`에 Impact.com
브랜드 4곳을 위한 변환 로직을 추가하겠다(Rakuten과 같은 패턴 — 5줄 이내,
CLAUDE.md 규정상 5줄 이하는 직접, 그 이상이면 서브에이전트로 처리).

## 2번. Amazon 어소시에이트 태그 발급

**코드는 이미 준비 끝났다.** `app/core/affiliate.py:20`이 이미
`settings.amazon_partner_tag`(=`.env`의 `AMAZON_PARTNER_TAG`)가 있으면 자동으로
Amazon 링크에 `?tag=...`를 붙여준다. **할 일은 태그 하나를 발급받아서
`.env`에 넣는 것뿐이다.**

### 순서

1. **가입 페이지 열기**: `affiliate-program.amazon.com` 접속 → "Sign up" 클릭.
2. **로그인**: 기존 Amazon 계정으로 로그인(구매용 계정과 같아도 무방, 다만
   결제 정보와 별개로 관리됨).
3. **웹사이트/앱 등록**:
   - "Website or mobile app you'll add" 란에 `compa.mwco.io` 입력.
   - **compa가 실제로 접속 가능해야 한다** — 지금 서비스가 재기동돼 있으니 OK.
     심사관이 실제로 사이트를 눈으로 확인한다.
4. **사이트 설명 작성**: "화장품 가격 비교 및 할인 이력 추적 서비스" 정도.
   "어떤 상품을 홍보할 건가"를 물으면 뷰티/화장품 선택.
5. **Associate ID(=태그) 만들기**: 가입 마지막 단계에서 "Store ID" 또는
   "Associate ID"를 직접 정할 수 있다. 예: `compa-20` 같은 형식(끝에 지역
   코드가 자동으로 붙는 경우도 있음 — 화면에 나오는 그대로 쓰면 됨).
6. **⚠️ 첫 판매 90일 룰**: Amazon Associates는 **가입 후 180일 이내 3건의
   판매가 없으면 계정이 자동 비활성화**된다(2026년 기준 정책, 승인 화면에
   명시돼 있을 것 — 정확한 숫자는 가입 시 뜨는 안내를 최종 기준으로 볼 것).
   즉 태그만 걸어두고 방치하면 안 되고, compa가 실제 트래픽을 받기 시작하는
   시점에 맞춰 신청하는 게 유리하다. **지금 신청해도 무방** — 어차피 심사에
   시간이 걸리고, 통과 후 판매 유예기간이 있다.
7. **필수 고지 문구 추가** (Amazon 정책상 의무): 사이트 어딘가(보통 푸터)에
   아래와 비슷한 문구가 있어야 한다:
   > "As an Amazon Associate, compa earns from qualifying purchases."

   이건 코드 수정이 필요하다 — **끝나면 나한테 알려주면 프론트 푸터에 이 한 줄
   추가하겠다**(5줄 이하 직접 수정 대상).

### 끝나면 나(Claude)한테 시킬 일

1. 발급받은 태그 값을 알려주면 → `.env`의 `AMAZON_PARTNER_TAG=` 뒤에 넣어줌
   (또는 직접 넣어도 됨 — `backend/.env`와 루트 `.env` 둘 다).
2. 넣고 나면 `app/core/affiliate.py`가 **아무 코드 수정 없이** 자동으로
   Amazon 링크를 제휴 링크로 바꾸기 시작한다. 확인 방법: Amazon 상품 하나
   찾아서 프론트에서 "구매하기" 링크를 눌러봤을 때 URL에 `?tag=`가
   붙어있으면 성공.
3. 푸터 고지 문구 추가.

## 3번. SMS 전용 브랜드 딜 신호 (Fresh 등)

**이건 코드보다 결정이 먼저다.** Fresh 같은 럭셔리 브랜드는 홈페이지·제휴
피드 어디에도 안 뜨는 할인을 **가입자 문자로만** 보낸다. 이걸 잡으려면
"누구 폰의 문자를 볼 것인가"부터 정해야 한다.

### 3-1. 과거 이력 확보 (한 번만 하면 되는 일)

- 와이프 문자함에 있는 과거 Fresh(등) 할인 문자를 **캡처(스크린샷) 또는
  복사**해서 전달받기.
- 형식은 상관없음 — 스크린샷 여러 장이어도 되고, 문자 내용을 그냥 옮겨
  적어도 됨. 날짜·할인율·브랜드명만 있으면 내가 구조화된 데이터로 정리하겠다.

### 3-2. 앞으로 자동 수집 방식 정하기 (택 1)

두 후보 중 **iOS 단축어(Shortcuts) 추천** — 기기 소유자(와이프)가 직접
설정·통제하는 방식이라 프라이버시상 가장 깔끔하다:

**옵션 A — iOS 단축어(추천)**
1. 와이프 아이폰에서 "단축어(Shortcuts)" 앱 열기.
2. "자동화(Automation)" 탭 → "+" → "메시지 받음(Message)" 선택.
3. 조건 설정: 발신자가 특정 번호/이름(Fresh 등)이거나, 메시지에 특정
   키워드("Fresh", "% off" 등)가 포함될 때.
4. 동작(Action): "URL 열기" 또는 "웹 요청 보내기(Get Contents of URL)"를
   선택해서, 문자 내용을 compa 서버의 특정 주소로 전송하도록 설정.
   (이 주소는 **내가 미리 만들어둬야** 하는 부분 — 아래 참고)
5. 매번 "실행 전 확인"을 켜두면, 와이프가 자동화가 실행될 때마다 확인
   후 허용할 수 있어 더 안심된다(자동 실행 대신 수동 승인).

**옵션 B — Apple 문자 포워딩**: 아이폰의 "메시지 포워딩" 기능으로 특정
번호의 문자를 다른 기기로 전달. 설정이 더 무겁고(Apple ID 연결 필요),
모든 문자가 넘어와서 필터링을 나중에 해야 함 — **옵션 A보다 권장 안 함.**

### 필요한 결정 2가지 (다음 세션 전에 정해주면 진행)

1. **Fresh 외에 다른 SMS 전용 브랜드가 또 있는지** — 와이프에게 구독 중인
   브랜드 문자 리스트를 확인해줄 것.
2. **옵션 A(단축어)로 진행할지 확정** — 확정되면 내가 그 "웹 요청 보내기"가
   가리킬 서버 엔드포인트(`/api/sms-signals` 같은 것)를 코드로 만들고,
   단축어에 붙일 정확한 URL을 알려주겠다.
